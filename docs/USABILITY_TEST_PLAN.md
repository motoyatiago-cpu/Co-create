# 阶段三：5名首次用户测试 · 待人工执行

目前没有真实受试数据，所有完成率、首次有效操作时间、卡点、主观评价均未测。自动化浏览器不能替代5名新用户；没有联系成员或虚构受试者反馈。

招募5名未接触这两款产品的用户，告知自愿参与，不收集密钥或私人聊天内容。每人同样任务，主持人先不解释入口；仅在明显停滞后协助，并标记“受助完成”。可使用示例数据和本地模式，无须付费API。

1. 回音结：读懂一句话，复制一个拟采用的回复，将结果收进回音簿并再次找到。
2. 自主找到照见或共鸣；说明两种回声区别，无API时完成一次本地对话。收起指南后重新找到它。
3. 剪片：使用示例，不上传素材，完成两道题、生成、播放并找到保存影片/海报。询问是否理解上传可选及本地生成。
4. 查看片库与日历，确认知道下一次从哪里继续。

计时起点为看到产品首页，首次有效操作为进入对应核心体验或使用示例；误点导航/滚动不算。分别记录独立完成、受助完成、未完成，不能把看到生成结果等同于已经保存导出。记录是否需回看指南、是否误以为本地模式调用云端模型。主观提问：用途是否清楚、最困惑的位置、是否知道下一步、自评难度1–5及原因。先保留原话，再汇总问题。
