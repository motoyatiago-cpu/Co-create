## 实际执行

- `npm run build`：TypeScript 严格检查及 Vite 生产构建通过，无缺失素材告警。
- `git diff --check`：通过。
- `npm run test:e2e`：桌面/手机共8项通过。测试用本机已安装 Edge（Chromium 内核），不是实际 iPhone 真机测试。
- ChatGPT in-app browser：亲自打开本机预览，点击进入按钮、打开/关闭成员名片、暂停漂浮，检查桌面与390×844手机视口。
- IAB可用，视觉验收未回退到独立 Playwright 浏览器。Playwright只用于可复现的自动化回归，因未安装其专用浏览器，设置 `PLAYWRIGHT_CHANNEL=msedge` 复用本机Edge。

复现自动验收（PowerShell，已安装Edge）：

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run test:e2e
```

其他环境可先执行 `npx playwright install chromium`，然后 `npm run test:e2e`。测试服务器仅绑定本机4175端口。

## 比对账本

| 比较点 | 概念证据与实现证据 | 修复/取舍 |
| --- | --- | --- |
| 文案 | 首页概念与首页截图：三行主标题、副标题、草稿提示、两入口、页底口号 | 所有文字均来自原任务或设计前确定的描述；首屏没有新增营销徽标、数据或商业能力承诺 |
| 布局与留白 | 首页左右文本/星云环，成员区简介/关键词、六列泡泡 | 保留主次关系；成员区工具栏单独一行，避免与说明、名片挤在一起 |
| 字体层级 | 概念的中文衬线标题；实际h1约76px，副标题28px，正文14–19px | 首轮h1偏小，已调大；使用系统中文衬线回退，不依赖外部字体网络 |
| 主色与点缀 | 深蓝、奶油文字、少量粉紫 | 锁定#131A3A/#F4E9D4/#F2A9C4；小字略提亮以提高可读性 |
| 插画处理 | 独立水彩星云环与水彩圆片 | 从概念另生成纯插画并压缩，不使用任何带UI的参考图作背景；环形插画仅为装饰、不可拦截点击 |
| 气泡与密度 | 概念六列、不同色调；实际六列/四列/三列/最窄两列 | 每人独立网格单元，45人仍自然向下延伸；按用户要求不做自由碰撞布局 |
| 名片形态 | 概念为奶油色侧卡，实际为奶油色原生弹窗 | 有意采用居中模态以在手机完整可读，提供键盘焦点管理；保留三关键词与两项信息层级 |
| 动画与响应式 | 轻微漂浮、不干扰文字 | 仅5px平移；可暂停；系统减少动画时禁用。手机把插画排到按钮下，保留可见CTA |

首屏文案逐项检查：品牌、五个导航、身份行、三个标题片段、副标题、简述、草稿提示、两个按钮、页码及候选口号全部对上预定内容。无未记录新增或缺失。

已按选定星云设计完成实际截图比对；无阻碍阅读、点击或响应式使用的未修复视觉问题。保留的有意适配包括系统字体、纯色无多余云纹的成员背景、工具栏独立行、居中弹窗、手机顺序布局。它是可交互实现，不是概念图的逐像素截图复刻。
