# V1.1 首页与成员体验交接

日期：2026-11-08（北京时间）。基线 `07cbadc`，开发分支 `feature/celia-home-team`。

## 完成范围

- P0：12张示例替换为31份已确认可公开的脱敏资料，逐字段与交接包比对一致。姓名/昵称、自述、关键词均保留原话，不生成头像、技能、交流意愿或角色。
- 数据兼容：`keywords: string[]` 允许0项或多项；增加可选 `nickname`、`intro`，技能与交流字段改为可选。有内容才展示，缺介绍时显示中性提示。
- P1探索：搜索覆盖姓名、昵称、自述、关键词及实际存在的其他字段。提供一个关键词选择入口，选项及人数直接来自成员自填关键词，逐字匹配；与搜索组合使用，可一键清除。
- P1名片：展示身份、昵称、自述和关键词，支持在当前筛选结果内“认识下一位”与首尾循环；只有一人时禁用下一位。保持同一个原生dialog，切换不重开弹窗，保留焦点；关闭后回到最初打开名片的泡泡。
- P1衔接：首页构图和主标题保持不变，增加认识伙伴的操作提示；团队简介缩短，8个团队关键词全部保留；收紧团队区及手机工具栏留白。
- 稳定性：按钮点击区域固定，内部视觉轻微漂浮；暂停与系统减少动画仍有效。修复React首次打开 `/#team` 等深链接时的锚点定位。
- P2：本轮取消星点兴趣入口，保持首页现有星云插画与交互稳定。

## 公开范围与数据边界

交接包最初标为待确认；用户随后在本次对话明确确认：**“已全部确认，按交接包脱敏范围公开”**。本次据此提交31条包内记录。

来源包已排除退出展示者；限定昵称的记录只保留包内昵称，不反查姓名。导入时校验31个唯一ID与字段白名单，并与候选数据完整比对。没有提交ZIP、原始表、内部审核表、联系方式或成员照片。

实际缺项：1位未填写介绍，4位未填写关键词；31位均没有独立的技能/学习意愿字段。界面保留这些缺省状态，不从自述拆出或推断新的个人字段。现有31人不被宣称为全组完整人数，容量通过独立45人测试资料验证。

## 构建和实际验收

- `npm run build`：TypeScript与生产构建通过。
- `npm run test:e2e`：**16项通过**，桌面与手机各8项；使用本机Edge的Chromium内核。
- 正式数据：31份记录、唯一ID、0/1/6关键词、缺介绍、昵称限定；界面内容与数据一致，原话未修改。
- 组合筛选：选项完全等于成员关键词集合，重复关键词计数及结果正确；组合搜索、无结果、清除返回全部通过。
- 名片：点击、Enter、Tab/Shift+Tab、Escape、关闭恢复焦点、下一位首尾循环、单人禁用通过。
- 容量：45张名片逐一点击；320、390、768、1440视口下边界无重叠、无横向溢出；包含长内容和触屏tap检查。
- 动画：默认内部视觉漂浮，按钮区域静止；暂停和 `prefers-reduced-motion` 禁用动画，交互仍可用。
- 独立体验：除HTTP检查外，实际点击三处入口打开新页，验证正确URL及页面加载；不代表对原产品生成/导出等全部内部功能重新验收。
- IAB人工检查：1440×1000桌面与390×844手机，检查真实成员、筛选及下一位。390×844的首排成员完整进入视口；自动测试另外保留设备默认较矮手机视口及四种宽度。
- `git diff --check`通过；与基线比较确认搭档文件无变化。

复现（PowerShell，本机已安装Edge）：
