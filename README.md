# Co-create
此仓库用于对小组交互性网站的创作。

## 本地开发

本分支使用 Vite + React + TypeScript + 原生 CSS。需要 Node.js 22.12+（本次验证使用 Node 24）。

```bash
npm ci
npm run dev
```

生产构建：`npm run build`；本地检查构建：`npm run preview`。

首页、成员墙、产品展厅与共创故事已集成。现已合入章节式导航和动态星云首页，团队区可切换∞星河轨道与立体名片。**请复用此工程，不要另起一套。**
